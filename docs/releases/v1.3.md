## 一句话

界面开始收敛：信息条贴到屏幕边、控制项收进二级菜单、文件名可以自己定。

## 新增

**横屏贴边信息条**

- 顶部「文件信息条」常驻，背景铺满屏幕顶边与左右边，只有内容避开挖孔
- 照片改为从信息条下沿开始铺，不再被状态栏压住
- 控制条浮在照片上，静置 4.5 秒淡出，点信息条或收到新图唤出
- 信息条内容：类型徽章 · 文件名 · 收图统计

**二级菜单**

- 格式勾选 + 发现相机 + 文件命名 合并为一个下拉菜单
- 相册入口删除（横屏、竖屏都不再保留）

**文件命名规则（`Naming.kt`）**

- 按 OM Capture 的三段式拼名：**前缀 - 基本 - 后缀**，留空的一段自动省略
- 每段可选：无 / 原始文件名 / 任意字符串 / 拍摄日期 `yyyyMMdd` /
  拍摄日期和时间（6 种预设，如 `YYMMDD_HHMMSS`）/ 连续号码（起始数字 + 位数补零）
- 对话框顶部实时示例，可「恢复默认」
- 默认规则「拍摄日期 - 连续号码 - 原始文件名」，即 `20261117-0001-P1170500.JPG`
- 规则存 `SharedPreferences`，重启不丢

**测试**

- 新增 `NamingTest` 8 例：补零、自定义文字、空段省略、日期、时间、非法字符、扩展名

## 改进

- 预览底色跟随主题：深色近黑、浅色纯白（原来恒黑，浅色主题下照片周围一片黑）
- 浮层文字与遮罩也按主题取色
- 手势模块重写：`ZoomState` 持有状态，`pointerInput` 固定以 `aspect` 为 key
  - 修掉「每帧重建手势、图片不跟手」的老问题
  - 锚点缩放公式 `offset' = c + (offset - c) * k + pan`，放大不会往角落跑
  - 边界钳制，松手不停在空白处
  - 1× 左右拖动跟手切图，超过 18% 屏宽才翻页
  - 双击以点击点为锚点放大到 2.6×，再双击回到 1× 并复位旋转/平移
- 保存目录固定 `DCIM/OM Phone` 且不可点击，只有文件名规则可进二级菜单

## 修复

| 问题 | 根因 | 处理 |
|---|---|---|
| 浅色模式下命名对话框发奶油色 | Material3 `AlertDialog` 的 `tonalElevation` 会用 primary 给底色染色 | `tonalElevation = 0.dp` 且 `surfaceTint = Color.Transparent` |
| 手势不跟手 | `pointerInput` 以 scale 为 key，每帧重建 | 固定 key，状态外置到 `ZoomState` |

## 已知问题

- 控制条会自动淡出，用户不清楚怎么再唤出；1.4 取消自动隐藏
