## 版本节奏

- **1.0**：协议链路先跑通，能连、能收、能落盘
- **1.2**：从「能用」到「好看」，横屏预览、主题、手势、RAW 修复
- **1.3**：信息条贴边 + 命名规则可自定义，界面开始收敛
- **1.4**：砍掉多余的一层，横屏只留一条信息栏，补边界反馈
- **1.5**：画廊覆盖整个目录，翻页从「拖一张图」变成「翻一页照片」
- **1.6**：修掉按 uri 去重导致的总数虚高与手势闭包过期，浮层配色跟着画面亮度走
- **1.7**：功能不动，把仓库整理成可公开的形态，逆向材料全部隔离在外

## 归档说明

从 1.7 起仓库不再提交二进制，也不提供预编译 APK：客户端 GUID 是设备专属凭据，
预编译包只对构建它的那台相机有效。需要 APK 请按 `CONTRIBUTING.md` 的说明本地构建。
`versionCode` 与 `versionName` 在 `app/build.gradle.kts` 中维护，安装时可据此确认是否覆盖升级；
构建产物可放到 `dist/`，该目录已被忽略。
