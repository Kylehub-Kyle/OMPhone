## 一句话

横屏砍掉多余的一层，只留一条说清楚所有事的信息栏；滑到头有明确反馈，断开不留残影。

## 新增

- **滑到边界有反馈**：最后一张继续往右、第一张继续往左时，图片带阻尼拉出后弹簧回弹，
  底部弹出深色胶囊提示「已经是最后一张了」/「已经是第一张了」，1.5 秒后自动消失
- **「拍摄时间」命名段**：除拍摄日期、拍摄日期和时间外，新增 `HHmmss` 纯时间选项
- **圆形大小徽章**：照片大小做成类似 RAW 的圈形徽章，紧跟在文件名后面

## 改进

**横屏：两条栏合并为一条**

```
● 未连接 ▾  [RAW] P1170500.ORF  (16.97 MB)      已收 4 · 55 MB   ⤢   ⚙   [连接]
```

- 状态栏与照片信息栏合并，**常驻显示，不再自动隐藏**
- 从左到右：连接状态 → 类型徽章 → 文件名 → 大小徽章 → 收图统计 → 打开 → 设置 → 连接/断开
- 连接状态移到最左，**点它弹出「连接相机」**；设置菜单里删掉重复的「连接相机」
- 「用其他应用打开」与「设置」两个图标互换位置
- 连接/断开按钮固定在最右，宽 72dp × 高 32dp
- 文件名用 `weight(1f, fill = false)`，让大小徽章紧跟名字，不被推到右边
- 背景仍铺满屏幕顶边；内容两侧各留 `max(左右安全边距) + 16dp`，同时避开挖孔与内屏 190px（58dp）圆弧边角
- 信息栏下方 1dp 分割线，照片紧贴其下沿

**竖屏**

- 去掉「打开文件」入口（`openGallery` 一并删除）
- 保存卡片不可点击，只有「文件名规则」可点
- 复位按钮加大
- 开始数字与位数由上下排列改为并排

## 修复

| 问题 | 根因 | 处理 |
|---|---|---|
| 断开后仍显示相机型号、IP | `stopCapture()` 只在部分分支清理状态 | 统一清空 `device` / `host` / `logLine`，`stage` 按需显示「未连接」；`ACTION_CONNECT` 先清再连 |
| 横屏左右箭头语义反了 | 左箭头错调 `onNext` | 左箭头 → 上一张（更旧），右箭头 → 下一张（更新） |
| 旋转/放大的照片盖住信息栏 | 预览区未裁剪，变换可溢出父布局 | 预览容器加 `clipToBounds()` |
| 信息栏点不到 / 提示不可见 | 手势层与浮层顺序 | 提示层放在预览 `Box` 最上层，`AnimatedVisibility` 淡入淡出 |

## 已知问题

- 双指捏合/旋转需手动确认（adb 无法模拟多指）
- App 冷启动只预览本次会话收到的照片，`DCIM/OM Phone` 里的存量文件不进画廊
- 圆角留白按内屏 58dp 取值，外屏（小屏折叠态）会显得略宽，属可接受范围
