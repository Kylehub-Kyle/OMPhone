## 一句话

第一次上真机跑通：RAW 能落盘、横屏能看图、深浅色跟随系统——从「能收」做到「能看」。

## 新增

- **横屏全屏预览**：整屏留给照片，底部一条半透明状态栏显示文件信息
- **格式选择改二级弹窗**：竖屏面板不再挤满三行勾选框
- **深浅色主题**：`Pal` 对象 + `darkColorScheme` / `lightColorScheme`，跟随系统切换
- **看图手势**（自定义 `awaitEachGesture`）
  - 双指缩放（上限 10×）、双指旋转
  - 放大后单指拖动平移
  - 未放大时左右拖动切图
  - 双击缩放；放大后底部浮出「复位」
- **预览增强**
  - ORF 解析内嵌 JPEG，直接显示真实画面
  - MOV 取首帧做封面
  - 本次会话没有记录时，回退显示 `DCIM/OM Phone` 里最新一张

## 改进

- 连接成功后按钮变红色「断开」，状态区显示 `OMSYSTEM OM-1 · 序列号`
- 顶部信息随连接状态实时更新，不再只有一句「已连接」

## 修复

| 问题 | 根因 | 处理 |
|---|---|---|
| RAW（ORF）保存必失败 | Android 14+ 不允许 `MediaStore.Files` 写 DCIM，抛 `Primary directory DCIM not allowed`；JPG 走 Images、MOV 走 Video 因此正常 | ORF 首选 `Images` 集合（DCIM 合法），`Files`/`Downloads` 兜底 |
| MOV 落盘后变成 `.MOV.mp4` | mime 与扩展名不匹配时 MediaStore 自动补后缀 | 写入后校验文件名并纠正 |
| 打开即崩 | 批量替换内置色值时把 `Pal` 定义本身也替换掉，属性自递归 | 恢复定义，颜色只引用不替换 |

## 已知问题

- 双指捏合/旋转未做自动化验证（adb 无法模拟多指）
- 横屏状态栏会遮住照片下沿，1.3 改为照片从信息条下沿铺
