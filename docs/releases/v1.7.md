## 一句话

功能与 1.6 一致，这一版只做「可以公开」：把逆向材料隔离出仓库，补齐开源工程该有的文件，
并把源码里能识别到个人的信息换掉。

## 新增

- 开源工程骨架：`LICENSE`（MIT）、`.gitignore`、`.gitattributes`、`CONTRIBUTING.md`、
  `SECURITY.md`、`CODE_OF_CONDUCT.md`
- `.github/`：Issue 表单（问题反馈 / 功能建议）、PR 模板、Android CI（单测 + 构建 + 产物归档）
- Gradle Wrapper（8.7），克隆后无需本机安装 Gradle
- README 重写为项目主页格式：能解决什么问题、安装、用法、结构、协议要点、隐私说明

## 改进

- **客户端 GUID 不再硬编码**：相机只接受白名单里的那一组，属设备专属凭据。改为构建时从
  `local.properties` 的 `ptp.client.guid` 注入（`buildConfigField`），仓库、Git 历史与 Release 产物都不含真实值；
  未配置时连接会明确提示「未配置客户端 GUID」，不再用一个假值去撞 Init Failed
- 抓包与逆向材料（`round3.pcapng`、`cmd_stream.txt`、`evt_stream.txt`、`tcp_flow.txt`、
  `om1_ptp_client.py`、`verify_photos.py`、`OM1_PTPIP_抓包逆向分析.md`）整体移到仓库外的
  `OM1-PTPIP-Research_PRIVATE/`，仓库内同时用 `.gitignore` 兜底
- APK 不再进版本控制（`dist/` 已忽略），仓库也不提供预编译包：预编译包必然带着某台设备的 GUID，对他人无意义
- 文档中示例 IP 统一为 `192.168.1.50` 这类通用地址，不再出现真实网段
- 版本目录与 CHANGELOG 的归档说明改为「APK 随 Release 分发」

## 修复

| 问题 | 根因 | 处理 |
|---|---|---|
| 公开源码会暴露个人电脑名 | `OmCamera` 的客户端名默认写死为主机名，会显示在相机的「连接至 PC」列表 | 默认值改为 `OM Phone`，并在注释里说明用途 |
| 线级测试同步该常量 | `PtpWireTest` 里复用了同一个字符串 | 一并改为 `OM Phone`，断言不依赖名称内容 |

## 已知问题 / 遗留

- 逆向分析文档与原始抓包仍留在本地私有目录，是否脱敏公开由维护者另行决定
- 应用未做 release 签名，Releases 里的 APK 为 debug 签名，仅适合自用与测试
